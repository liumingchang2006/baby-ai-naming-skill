# Baby AI Naming Skill - 宝宝AI起名师

OpenClaw / WorkBuddy 技能包：把「凭感觉起名」变成**可解释、可比较、可检验**的工程化流程，并叠加中华起名的文化惯例参考。

## 功能特点

- 🍼 **两大模式**：起名（生成候选）＋ 评估（对已有名字横向打分选最优）
- 🔍 **五维评估**：音律（声调平仄）、形义（字形字义）、传播（重名率/记忆度）、文化（寓意与典故）、合规（谐音/方言/避讳）
- 🚫 **硬约束一票否决**：「起名十忌」可逐条检验，不靠玄学断言
- 📚 **可插拔文化参考**：生肖宜忌、五格剖象、五行补缺——仅在用户主动要求并给出出生信息时启用
- 🧪 **真实复评案例**：仓库内附柳姓二胎女孩 10 个候选的完整复评（`references/`）

## 核心思想

> 起名是生成式任务的一个特例——用「参数化需求」缩小名字空间，用「维度化方法」评估候选，让主观的文化寄托与客观的传播规律结合，最大化名字的总价值。

## 解决什么问题

| 家长痛点 | 技能对应机制 |
|---|---|
| 名字好听，方言一念翻车 | 谐音三查（普通话 + 方言 + 姓氏连意）+ 特殊姓氏黑名单 |
| 重名率高，点名一片 | 大姓优先双名、避开爆款字，打量级差异化 |
| 寓意讲不清，只能说「感觉不错」 | 每个候选给出可核验的维度理由，而非形容词堆砌 |
| 被算命话术绑架 | 玄学维度全部降级为「可选参考」，不进入一票否决 |

## 安装使用

### 方式一：手动安装

```bash
git clone https://github.com/liumingchang2006/baby-ai-naming-skill.git

# WorkBuddy
cp -r baby-ai-naming-skill ~/.workbuddy/skills/baby-ai-naming

# OpenClaw
cp -r baby-ai-naming-skill ~/.openclaw/skills/baby-ai-naming
```

### 方式二：对话触发

装好后直接说：

```
给宝宝起名，姓柳，女孩，姐姐叫柳洛菲，希望文艺一点、别太生僻
```

或做评估：

```
帮我看下这几个名字好不好：柳洛瑶 / 柳知微 / 柳念安
```

需要字辈、避讳长辈、方言地域时一并告知，硬约束检查会更准；要生肖 / 五格 / 五行参考时主动说明并附出生信息。

## 来源与立场

- 工程内核蒸馏自蔡凯龙《一本书搞定起名：AI起名指南》（电子工业出版社，2025，ISBN 9787121500152）的目录结构与公开内容。
- 传统姓名学 corpus 提炼自谢海东《好姓名，好人生：中华起名大观》（起名十忌、声调平仄、字义字形、生肖宜忌、五格剖象、五行数理），属可公开引用的文化/方法类内容。
- 本技能立场：**起名当工程而非玄学**。生肖宜忌、五格数理、五行补缺均为「可选文化参考维度」，不主动断言吉凶，也不进入硬约束一票否决；不处理企业/品牌命名，不替代户籍登记与民俗择日。
